# Reference screenshots

Screenshots of each game's real character select screen, used as the visual target when building templates. They are reference material only and are not shipped with the site.

Source: [SmashWiki, "Character selection screen"](https://www.ssbwiki.com/Character_selection_screen) (images hosted on ssb.wiki.gallery).

One folder per game: `smash-64`, `melee`, `brawl`, `smash-4-wii-u`, `smash-4-3ds`, `ultimate`. Each holds the full roster, the starting roster and the "Ready to Fight" banner where available.
