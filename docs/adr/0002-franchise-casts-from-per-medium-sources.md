# Franchise casts come from per-medium sources behind one adapter

No single source lists every franchise's cast with usable images, so casts are pulled from per-medium APIs (AniList for anime and manga first, then IGDB, TMDB and Comic Vine) behind one adapter interface, added one at a time. Fandom wiki scraping was rejected for inconsistent structure and awkward terms of use, and Wikidata for poor images. Because any source can come back empty or wrong, adding a fighter manually by name and image is always available.
