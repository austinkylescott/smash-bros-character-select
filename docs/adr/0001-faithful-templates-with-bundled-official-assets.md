# Faithful templates with bundled official assets

Templates aim to be almost indistinguishable from the real character select screens, so the site bundles Nintendo's official portraits, menu music and sound effects rather than shipping an asset-free homage or hotlinking a wiki. We accept the takedown risk that every fan site carries; to contain it, all official art and audio sits behind one swappable asset layer so it can be removed or replaced without touching template or roster code.

## Considered Options

- **CSS homage with no official assets**: rejected because it undercuts the core promise of viewing the real rosters as they looked.
- **Hotlinking a wiki or fan API at runtime**: rejected as fragile and a burden on the host.
