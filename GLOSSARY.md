# Smash Bros Character Select

A site for viewing and creating Super Smash Bros.-style character select screens, using casts from Smash itself or from any other franchise.

## Language

**Fighter**:
A selectable character on a screen, whether an official Smash fighter or a character brought in from any other franchise.
_Avoid_: Character, entry, item

**Franchise**:
Any media property (game, anime, film, TV, comic) whose cast can be brought in as fighters. Not limited to series represented in Smash.
_Avoid_: Series, universe, category

**Roster**:
An ordered collection of 1 to 120 distinct fighters, with a name, that a user creates, saves and shares. A roster may mix franchises and is independent of any template, though it names a default one.
_Avoid_: List, tier list, lineup

**Pool**:
The holding tray of fighters pulled from a franchise, from which a user picks fighters into a roster.
_Avoid_: Tray, bank, unranked, cast list

**Shared Roster**:
A frozen copy of a roster published at a link. Later edits to the original do not change it.
_Avoid_: Snapshot, published list, public roster

**Remix**:
To copy a shared roster into one's own rosters for editing.
_Avoid_: Fork, clone, duplicate

**Official Roster**:
A read-only roster matching the fighters and order of a real Smash game.
_Avoid_: Default roster, real roster

**Template**:
The visual style, layout rules and behaviour of one Smash game's character select screen. There are six: Smash 64, Melee, Brawl, Smash for 3DS, Smash for Wii U and Ultimate. Any roster can be shown in any template.
_Avoid_: Theme, skin, style

**Screen**:
A roster rendered in a template.
_Avoid_: Scene, board, page

**Smash for Wii U**:
The template based on the Wii U game's screen: a band of named portraits above the player panels.
_Avoid_: Smash 4, Sm4sh

**Smash for 3DS**:
The template based on the 3DS game's screen: a grid of unnamed portraits and separate player cards, shown as the handheld's two displays stacked.
_Avoid_: Smash 4, Sm4sh

**Backdrop**:
The scenery behind a screen's slots and player panels, which may move, as the real game's did.
_Avoid_: Background, scene, wallpaper

**Portrait**:
The image of a fighter. Official fighters have one per game they appeared in and fall back to the nearest game that has them; other fighters have one source image cropped for the slot and for the player panel.
_Avoid_: Face, icon, mugshot, render

**Random Slot**:
A special slot that picks a fighter at random. Any roster can switch it on or off; it is not a fighter.
_Avoid_: Random fighter, mystery slot

## Selection

**Hand**:
The on-screen cursor that picks up and drops tokens.
_Avoid_: Cursor, pointer, hand selector

**Token**:
A player's chip, dropped on a fighter to select it for that player.
_Avoid_: Chip, coin, marker

**Player Panel**:
The area showing one player's selected fighter. Each template allows as many as its game did, added and removed with that game's own controls.
_Avoid_: Player slot, player card, player box
