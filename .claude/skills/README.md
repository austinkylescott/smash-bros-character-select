# Vendored agent skills

These skills are copied from [mattpocock/skills](https://github.com/mattpocock/skills)
(plugin `mattpocock-skills` v1.2.3, MIT, see `LICENSE-mattpocock-skills`).

They live in the repo so every Claude Code session, including cloud and mobile
sessions, loads them from the checkout. Cloud sessions don't install plugin
marketplaces that a repo declares in `.claude/settings.json`.

To update, copy the skill directories again from a newer release of upstream.
